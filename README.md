# 🕯️ SOBRE O PROJETO

A **Gestão de ONGs com Transparência** é uma plataforma desenvolvida para facilitar a administração de entidades do terceiro setor. O projeto busca solucionar desafios recorrentes no gerenciamento de ONGs, integrando uma landing page interativa e de forte apelo visual com um painel administrativo completo e funcional.

Com foco principal em **transparência e facilidade de acesso**, a plataforma organiza cadastros de beneficiários, administradores e ações sociais ativas de forma simples, eficiente e segura.

---

# 🚀 DESAFIOS E SUPERAÇÕES

No desenvolvimento, o maior desafio foi construir um sistema estruturado e expansível em PHP puro, aliando dynamic UI com animações avançadas:

| Desafio | Tecnologia Aliada | Como a tecnologia ajudou |
| :--- | :--- | :--- |
| **Organização do Código** | **PHP (MVC + Factory)** | Separação clara entre regra de negócio, visualização e instanciação de dados, permitindo manutenibilidade e escalabilidade. |
| **Animação da Landing Page** | **GSAP** | Criação de transições dinâmicas e da roleta interativa de ações na landing page sem comprometer o desempenho visual. |
| **Layout Adaptável** | **CSS3 & Bootstrap** | Combinação de componentes prontos do Bootstrap com estilos customizados em CSS3 para garantir elegância e responsividade. |
| **Persistência de Dados** | **phpMyAdmin / MySQL** | Modelagem relacional para vincular novos beneficiários, administradores e ações sociais de forma consistente. |
| **Publicação e Deploy** | **cPanel** | Configuração de servidor de hospedagem, permissões de arquivos e conexão segura com a base de dados em produção. |

# 💎 FUNCIONALIDADES CHAVE

### 🌐 LANDING PAGE & ENGAJAMENTO
- **Roleta de Ações Sociais:** Apresentação interativa e animada via GSAP para destacar projetos e campanhas ativas.
- **Formulário de Beneficiários:** Cadastro simples e direto para pessoas interessadas ou necessitadas de suporte.
- **Responsividade Total:** Interface otimizada para telas mobile, tablets e desktops.

### 🔐 PAINEL ADMINISTRATIVO & GESTÃO
- **Gestão de Administradores:** Cadastro e gerenciamento de perfis administrativos.
- **Controle de Beneficiários:** Visualização e organização de novos cadastros recebidos via plataforma.
- **Gestão da Roleta:** Adição, edição e remoção de ações sociais que aparecem na landing page.

# 🛠️ ARQUITETURA E TECNOLOGIAS

### Padrão Arquitetural: MVC + Factory
O backend foi construído seguindo boas práticas de desenvolvimento orientado a objetos em PHP:

- **Model:** Representa os dados e a lógica de persistência no MySQL.
- **View:** Interface gráfica em HTML/CSS/Bootstrap que interage com o usuário.
- **Controller:** Intermedia as requisições, aplicando validações e regras de negócio.
- **Factory:** Padrão de projeto responsável pela criação e instanciação flexível de objetos e conexões.

| Tecnologia | Função no Projeto |
| :--- | :--- |
| **PHP (MVC + Factory)** | Processamento backend, lógica do sistema e manipulação do banco de dados. |
| **CSS3 & Bootstrap** | Estilização, componentes visuais e grid responsivo. |
| **GSAP (GreenSock)** | Animações fluidas e efeitos interativos na landing page e roleta. |
| **MySQL & phpMyAdmin** | Armazenamento relacional e gestão da base de dados. |
| **cPanel** | Servidor de hospedagem da aplicação em ambiente de produção. |
